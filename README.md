## ☕ 支持我的开源创作

我长期开发和维护一些 Windows 工具、浏览器扩展及效率工具。

目前主要维护：
- [Shazao-markdown](https://github.com/yakoye/Shazao-markdown) — Windows Markdown编辑软件，快速、简明、小巧、易用、强大，单 EXE
- [YeImageViewer](https://github.com/yakoye/YeImageViewer) — Windows 看图软件，好用美观又极速
- [CapturaYe](https://github.com/yakoye/Captura_Ye) — Windows 录屏软件，支持批量提取帧保存为图片/gif/视频
- [WindowMark](https://github.com/yakoye/WindowMark) — Windows 窗口工具，窗口书签/窗口边框着色/窗口置顶/窗口拖拽/剪贴板保护
- [PiInput](https://github.com/yakoye/PiInput) — windows 中文输入法，小巧，极简，支持全拼/双拼，快捷命令和输入
- [RegCalc64](https://github.com/yakoye/RegCalcTextTool) — 64-bit 寄存器计算工具
- [ContentRadar](https://github.com/yakoye/ContentRadar) — 文本/内容辅助工具，notepad++插件/vscode插件
- [NppAlign](https://github.com/yakoye/NppAlign) - notepad++插件，对齐工具
- [siyuan-drawnix-mind](https://github.com/yakoye/siyuan-drawnix-mind) - 白板+思维导图工具

如果这些项目对你有帮助，也可以通过爱发电支持后续开发：
